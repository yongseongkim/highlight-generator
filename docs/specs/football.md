# 축구 하이라이트 SPEC

상태: 종목 엔진·자동 구장 탐색의 설계. [공통 SPEC](README.md)의 근거·검토 계약을 따른다.
기준은 IFAB 11인제이며 [2026/27 자료](https://www.theifab.com/laws-of-the-game-documents/?language=all&year=2026%2F27)를 참고한다.
풋살·소규모 축구·유소년의 구장과 경기 규칙은 별도 프로필이다. `football`이라는 이름만으로 동일 규격을 적용하지 않는다.

## 하이라이트와 필요한 증거

| 후보 장면 | 발견 신호 | 추가 확인 | 반례·미확인 항목 |
| --- | --- | --- | --- |
| 골·득점으로 이어진 공격 | 슈팅·골문 주변 공·골키퍼 반응, 명시적 골 이벤트 | 공격 시작, 유효한 경기 결과의 출처, 취소/수정 | 관중 환호·골 세리머니·2D 공 위치만으로 골 확정 불가 |
| 유효 슈팅·세이브·골대 근처 기회 | 슈팅 직전 동작, 공 이동, 골키퍼 반응 | 공의 실제 관측·골문 관계와 후속 상황 | 킥 포즈가 모두 슈팅은 아님 |
| 드리블·탈압박·개인 돌파 | 공과 공격수 이동, 수비수와의 관계 변화 | 연결된 전개와 제어 주체 | 선수가 빠르게 달리기만 하는 장면 |
| 스루패스·크로스·연계 | 공의 전진/횡단과 여러 선수의 연속 관여 | 패스 전후 관측과 실제 전개 | 가까운 선수에게 공 소유권을 단정 |
| 태클·차단·수비 후 역습 | 공 제어·이동 방향 변화, 팀 전개 | 접촉 주변과 전환 이후 상황 | 2D 겹침으로 태클 성공·파울 판정 |
| 세트피스·공중볼 경합 | 정지 상황 이후 전개, 공·선수 움직임 | 재개 종류/공격 전개와 후속 결과 | 헤더 동작·프리킥 준비만으로 결과 확정 |
| 중요한 경기 상황 | 검증 가능한 점수·시간·사용자 선호 | 당시 공격·수비와 경기 결과의 출처 | OCR 한 장으로 결승골·역전 확정 |

골이 없는 좋은 수비·개인 돌파·패스도 후보로 유지한다. 기본 관심도는 위협적인 전개·수비·개인 기술·팀 연계·상황으로
분해하며, 실제 골의 검증 상태와 따로 기록한다.

## 구장·골문 탐색

[IFAB Law 1](https://www.theifab.com/laws/latest/the-field-of-play/)은 구장 길이·폭을 범위로 허용한다.
따라서 105×68m를 모든 영상의 정답으로 고정하지 않는다. 실제 규격을 모르겠으면 `field_length_m`, `field_width_m`은
미확인으로 두거나 여러 규격 가설을 평가한다. 성인 표준 골문은 안쪽 폭 7.32m·높이 2.44m다.

1. 잔디 후보 마스크로 배경·관중을 줄이되 흙/인조잔디·그림자·비·밤 경기를 별도 조건으로 처리한다.
   녹색이 아니라고 구장을 배제하거나, 녹색 영역을 곧 경기장 경계로 삼지 않는다.
2. 사이드/골라인, 하프웨이, 페널티/골에어리어, 센터 서클·원호를 의미별 후보로 찾는다.
3. 점과 선을 함께 사용하는 [PnLCalib](https://github.com/mguti97/PnLCalib),
   비교 기준인 [TVCalib](https://github.com/MM4SPA/tvcalib)로 카메라/도면 가설을 평가한다.
   현재 가중치는 주로 축구 중계 분포이므로 동호회 고정 카메라의 정확도는 별도 평가한다.
4. fit에 쓰지 않은 선과 원호에서도 일치하는지 검사한다. 평면 homography와 렌즈 왜곡, 3D 골문 관측을 구분한다.
   광고판·관중석·풋살 표시선이 만든 가설을 반례로 검사한다.
5. 팬·틸트·줌은 단순한 이미지 평행 이동이 아니다. 카메라 구간별로 보정을 갱신하고 stale 상태에서는 미터 좌표 규칙을 중단한다.
6. 경기 중계의 컷·리플레이·클로즈업은 카메라 구간을 분리한다. 리플레이를 새로운 라이브 플레이로 중복 계산하지 않는다.
   원본 PTS와 경기 시계는 다른 좌표이며, 시계가 멈춰도 원본 시각을 다시 쓰지 않는다.
7. 팀·전반/후반·실제 골문 ID로 공격 방향을 관리한다. 화면 오른쪽으로 움직였다고 항상 공격으로 판단하지 않는다.

골문과 공은 지면 위의 물체다. 지면 homography로 공의 골라인 통과나 높이를 확정하지 않는다.
좁은 시야에서 골문이 보이지 않으면 진행 방향만으로 가상의 골문을 확정하지 않는다.

## 공격 전개와 경기 결과

| 상태 | 전이 후보 | 보존해야 할 불확실성 |
| --- | --- | --- |
| `unknown` / `loose_ball` | 공 제어·명시적 공격 시작 | 가까운 선수의 팀으로 임의 배정하지 않음 |
| `build_up` | 패스·운반·침투의 관측 | 팀/선수 ID 전환과 공 가림 |
| `chance_candidate` | 슈팅·박스 진입·크로스·경합 | 행동 spotting의 오탐과 경기장 좌표의 품질 |
| `outcome_candidate` | 골/세이브/아웃/중단 후보 | 유효한 경기 결과와 정확한 순간은 별개 |
| `restart` | 검증 가능한 재개 이벤트 | 골 취소·정정·리플레이 중복 |

명시적 공격 시작이 있으면 그 시점부터 결과까지 보존한다. 없으면 기존 골 이벤트 경로의 기본 앞 15초 맥락이나
bounded 움직임 문맥을 사용하고, 공격 전개 전체를 관측했다고 주장하지 않는다.
득점 중심의 기존 `highlight-plays`는 계속 외부 `goal` 이벤트가 필요하다. 새 행동 모델의 출력은 우선 이벤트 가설이다.

[IFAB Law 10](https://www.theifab.com/laws/latest/determining-the-outcome-of-a-match/)의 골 조건에는
공 전체의 골라인 통과, 골대 사이/크로스바 아래 위치, 득점 팀의 반칙 여부가 포함된다.
일반 단일 카메라에서 공 중심이 골문 사각형 안에 들어왔다는 관측만으로 이를 검증할 수 없다.
점수판·심판/공식 이벤트·재개는 보조/외부 근거로 기록하고, 득점 취소가 확인되면 기존 후보와 정정 관계를 보존한다.
오프사이드·핸드볼·파울의 자동 심판은 이번 범위가 아니다.

## 모델과 실행 계획

| 역할 | 우선 후보 | 사용 범위 |
| --- | --- | --- |
| 선수·공 검출 | 기존 YOLO; 축구공 데이터로 검증/학습한 검출기 | 작은 원거리 공을 위해 타일/crop와 연속 관측 검토 |
| 선수 추적 | ByteTrack; 이동 카메라에서 BoT-SORT 비교 | ID·가림·카메라 이동을 기록; 팀/등번호와 별개 |
| 독립 발견·짧은 표적 추적 | SAM3 발견 + SAM2.1/SAMURAI 추적 | 새 공/선수를 다시 찾는 경로와 지정 표적 추적을 분리 |
| 구장 보정 | PnLCalib / TVCalib | 카메라 구간별 선·점 관측이 충분한 시점 |
| 행동 시점 후보 | [T-DEED](https://github.com/arturxe2/T-DEED), [SoccerNet Team Spotting](https://github.com/SoccerNet/sn-teamspotting) | 해당 checkpoint의 label set에 있는 사건만 제안; 동호회 분포의 전이 성능 확인 |
| 관심도 검토 | 선택적 VLM + 원본 프레임·관측 패킷 | 하이라이트 관심도·반례 확인; 새 경기 판정 금지 |

[SoccerNet Game State Reconstruction](https://github.com/SoccerNet/sn-gamestate)은 구장·선수 추적·팀/신원 정보를
연결하는 참고 파이프라인이다. 하나의 가벼운 범용 모델이 아니며 전체를 Mac 기본 경로로 그대로 채택하지 않는다.

포즈 저주기·독립 발견과 별도로 공 추적/행동 모델에 필요한 연속 입력을 예약한다.
중계용 spotting 모델의 프레임 추출·입력 길이·시간 stride는 모델 설정을 보존한다.
스파스 키프레임 몇 장을 연속 영상 모델에 그대로 대입하지 않는다. 세부 모델·가중치·라이선스는
[조사 보고서](../research/vision-models-2026-11-19.md)를 따른다.

## 수용 기준

- 축구/풋살, 실제 규격 차이, 팬·줌·컷·렌즈 왜곡·부분 구장을 분리해 검증한다.
- 공격 방향 변경·같은 색 유니폼·원거리 작은 공·골키퍼/심판 혼동을 검사한다.
- 리플레이·득점 취소·점수판 지연이 별도의 새 골로 승격되지 않아야 한다.
- 공이 골문 안쪽처럼 보이는 빗나간 슛·측면 그물·가림을 포함해 골 가설의 반례를 검토한다.
- 포즈 후보 밖의 세이브·패스·수비도 후보가 될 수 있어야 한다.
- 이벤트 spotting 정확도, 공 관측 recall, 선수 ID 전환, 공격 단위 완결성, 관심도·처리 시간을 별도로 평가한다.
