# YOLO·SAM 추론

M4 Pro MacBook(GPU 20코어, 통합 메모리 48 GB)에서 같은 배드민턴 영상 세 편, 총 33분 47초를 처리했습니다.
세 실행 모두 포즈를 새로 추론했습니다.

| 분석 방식 | 입력과 SAM 호출 | 총 소요 시간 | 측정일 |
| --- | --- | ---: | --- |
| YOLO11s 포즈 | 너비 1920 px, 3프레임마다 추론. 디코딩·추적·캐시 저장 포함 | 22분 42초 | 2026-10-31 |
| 포즈 + 농구 슛 규칙 | 같은 포즈 설정, 후보 구간에서 SAM 28,941회 | 4시간 30분 35초 | 2026-11-01 |
| 포즈 + 배드민턴 후보 상세 분석 | 너비 1280 px, 포즈 최대 10 FPS, SAM 180회 | 9분 40초 | 2026-11-02 |

농구 슛 규칙을 배드민턴 영상에 적용한 실행에서는 SAM 분석이 전체 시간의 91%를 차지했습니다.
배드민턴 후보 상세 분석은 포즈 해상도와 주기, SAM을 실행할 프레임을 함께 바꿨습니다.
처리 시간 1초당 분석한 영상 길이는 포즈 단독 1.49초, 농구 규칙 0.125초, 배드민턴 규칙 3.49초였습니다.
표의 시간은 클립과 오버레이 출력을 제외합니다. 마지막 실행에서 후보 클립 60개를 출력하는 데 별도로 16.55초가 걸렸습니다.

## 입력 영상과 실행 환경

세 영상 모두 VP9 1920 × 1080, 약 59.94 FPS이며 모든 실행에서 원본 121,399프레임을 디코딩했습니다.
MacBook Pro는 CPU 14코어, GPU 20코어이며 macOS 26.5, Python 3.11.13, PyTorch 2.15.0, Ultralytics 8.4.175를 사용했습니다.
OpenCV 디코딩과 선수 추적은 CPU에서, YOLO11s 포즈와 SAM 3 추론은 MPS에서 FP16으로 실행했습니다.
