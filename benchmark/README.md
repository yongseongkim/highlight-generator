새 측정 결과는 위 표에서 해당하는 작업의 문서에 추가합니다.
측정일, 입력 영상, 장치, 모델 설정을 적고 영상별 소요 시간에 새 추론, 캐시를 읽어 분석하는 작업, 영상 출력 중 어느 단계가 포함됐는지 밝힙니다.
Mac 자원 사용량과 실제로 확인한 결과도 함께 기록합니다.
실행 명령과 Mac 자원 지표를 읽는 방법은 [프로젝트 README](../README.md#벤치마크와-mac-성능-추적)에 있습니다.
